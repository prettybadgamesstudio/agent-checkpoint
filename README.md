# Agent Checkpoint

A small Papers, Please-style browser game that walks students through setting up OpenCode
(an AI coding agent) with a free model, prompting it to build a game, and adding art tools via MCP.

Made for the workshop *Beyond the Message: game design for social change* (Thammasat University, 2026).

Play it: open `index.html` in a browser, or visit the GitHub Pages site for this repository.
